# Sprint 1.1.5 — Editor variants

Tracks Jira INK-42 / INK-34.

## Variants
- `simple` — minimal toolbar
- `agent` — AI prompt bar + agent chrome
- `docx` — paper canvas + classic toolbar
- `notion-like` — blocks, slash, floating inline toolbar

## Design north star
Professional Editor.js / Tiptap level chrome — floating contextual UI, generous whitespace, not template-y.

## Deliverables
- Shared core; shell differs per variant
- Portal playground mode switcher
- Docs GIF per variant

PRs target `release/1.1.5`.
